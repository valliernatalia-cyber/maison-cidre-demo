# La Maison du Cidre — démo de refonte

Démo non officielle de refonte pour le site de La Maison du Cidre.

Le prototype présente :

- une page d'accueil plus moderne et immersive ;
- un parcours clair pour préparer une visite ;
- une boutique interactive avec filtres, panier et demande de commande ;
- une mise en valeur des photos, produits et contenus publics existants.

## Publication Netlify

Ce dossier est un site statique. Il peut être publié directement sur Netlify depuis GitHub.

Paramètres Netlify recommandés :

- Build command : laisser vide
- Publish directory : `.`

Le fichier `netlify.toml` contient déjà cette configuration.

## Note

Cette démo utilise des contenus et images publics du site existant uniquement à des fins de présentation commerciale.
